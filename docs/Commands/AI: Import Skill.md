Imports an [Agent Skill](https://agentskills.io) into the first folder in `ai.skills.paths` (default `Library/AISkills/`).

Accepts a GitHub skill folder URL (e.g. `https://github.com/anthropics/skills/tree/main/skills/pdf`), which imports every file in the folder, or any URI to a `SKILL.md`, which imports just that file.

See [[Skills]] for details.
